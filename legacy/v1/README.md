# Flowline v1 — the original hackathon build

These files are the original **Flowline v1** build by the **Tech Wolves** team at the
IEEE Young Professionals Industry Hackathon (October 2–4, 2026, Energy & Infrastructure
stream, Case 10). v1 is the corridor **Risk Ranking** with its explicit risk policy,
explainable ranks, the planner's agent drafts and the Decision Log. All of these still run
in v2 as the *Risk Ranking* and *Decision Log* tabs.

- [`HANDOFF.md`](HANDOFF.md): the v1 product plan and team handoff (scope owner: David,
  [@ovie-d](https://github.com/ovie-d)).
- [`CODING_GUIDELINES.md`](CODING_GUIDELINES.md): the coding conventions the team built v1
  with.
- [`agent_starter.py`](agent_starter.py): the hackathon starter script (count-only vs
  count × consequence ranking) that v1 set out to improve on.

They are kept as written, for credit and history. Paths, commands and "current"
statements in them describe v1, not the v2 Hazard Forecast. For v2, start with the
[main README](../../README.md).
